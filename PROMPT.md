# Grow.Media: Phase-Wise Master Build Prompt

> Reusable prompt to build (or rebuild/extend) **Grow.Media** with any capable AI coding assistant.
> Run phases in order; each phase ends with acceptance checks. The live implementation of this prompt is the repository it sits in.

---

## 0. Concept decision (why this site)

**Domain:** Grow.Media ("Grow Media")
**Concept:** A free **growth-media hub for creators and small businesses**: free calculators, in-depth playbooks, a curated video academy, a personalized growth-plan lead engine, contests, a talent network and supporter funding.

**Why this beats the alternatives:**

| Option | Ad CPC profile | Audience size & intent | Lead value | Verdict |
|---|---|---|---|---|
| Creator & SMB growth hub (chosen) | Digital marketing / SaaS: commonly ~$4–12+ CPC in the US | Creator economy ≈ $250B, projected ≈ $480B by 2027 (Goldman Sachs) | High: agencies, SaaS, freelancers pay for qualified leads | **Build** |
| Horticulture "growing media" (coco coir, rockwool) | Low-to-mid consumer CPC | ~$4–5B market, mostly B2B commercial growers | Low for a publisher | Reject |
| Generic "media" news site | Low CPC, heavy competition | Large but unfocused | Low | Reject |

**Revenue stack:** AdSense Auto Ads (high-CPC marketing/SaaS advertisers) + growth-plan leads (sell/refer to agencies & freelancers) + sponsorships (newsletter, tools, contests) + supporter contributions + talent-network matching + domain/website acquisition inquiries.

## Global rules (apply to every phase)

- **Stack:** static HTML/CSS/vanilla JS, generated by a Python build script; hostable on **GitHub Pages free plan (main branch, root)**. No server code, no build step on GitHub.
- **Paths:** all internal links relative, so the site works at `https://<user>.github.io/grow-media/` and at `https://grow.media/`. Canonicals and sitemap point to `https://grow.media/`.
- **AdSense:** in every content page `<head>`:
  `<script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js?client=ca-pub-6620975821265271" crossorigin="anonymous"></script>`
  plus `<meta name="google-adsense-account" content="ca-pub-6620975821265271">`. Use Auto Ads (no hard-coded ad slots). **No ads** on thank-you and 404 pages.
- **ads.txt:** `google.com, pub-6620975821265271, DIRECT, f08c47fec0942fa0`
- **Top bar on every page:** "Contact, if you are interested in this website/domain name/Sponsorship/Advertisement/Partnership" → `https://web.works/contact`.
- **Single private inbox:** all forms and contact deliver to the owner's one inbox via an AJAX form-processing endpoint (FormSubmit). The address must **never** appear in HTML, visible text, or repository source: store it only as an encoded char-code array that is decoded in the browser at submit time. "Email us" links open the mail client via JS.
- **Trademark safety:** never imply affiliation with any "Grow", "Grow Media" or "GrowMedia" brand (note: Mediavine holds live US "GROW" registrations for a creator product). Ship a full trademark & copyright disclosure page plus a footer notice.
- **Content honesty:** original writing only; no fabricated statistics, testimonials, subscriber counts, winners or case studies. Benchmarks are presented as hedged ranges.
- **Accessibility:** WCAG 2.2 AA intent: skip link, focus states, labels, keyboard-operable UI, reduced motion.

## Phase 10: QA, deploy and launch

**Prompt:**
> Run Playwright: screenshots at 390px and 1366px, zero page errors, wizard end-to-end with the form endpoint intercepted, tool outputs, search. Check every internal link. Grep the whole repo to confirm the inbox address does not appear. Commit to `main` and push to `github.com/WEBWORKSA1/grow-media`. Enable GitHub Pages (Deploy from branch → main → /root).

**Owner launch steps:**
1. **FormSubmit activation:** submit any form once; click the activation link FormSubmit sends to the inbox. Forms deliver after that.
2. **Custom domain:** in repo Settings → Pages → Custom domain enter `grow.media`, then at the registrar add A records `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` (and AAAA if desired), plus `www` CNAME → `webworksa1.github.io`. Enable "Enforce HTTPS".
3. **AdSense:** add the site `grow.media` in AdSense, confirm ads.txt is found, request review. Enable Auto Ads. For EEA/UK traffic, turn on Google's certified CMP under Privacy & messaging.
4. **Search Console:** verify the domain and submit `https://grow.media/sitemap.xml`.
5. **Payments (optional):** paste PayPal/Stripe/BMC/Ko-fi URLs into `assets/js/config.js`.
